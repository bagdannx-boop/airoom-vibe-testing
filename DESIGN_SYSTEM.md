# DESIGN_SYSTEM.md

## Порядок внимания

1. Заголовок — главная мысль сцены.
2. CTA «Перейти в Telegram» / «Подписаться» — идёт сразу за заголовком, взгляд должен приходить к нему естественно, без прокрутки.
3. Поясняющий текст (`.lead`) — объясняет и дополняет, не конкурирует с заголовком и CTA.
4. Второстепенные детали — самые лёгкие по весу.

## Роли текста

- **Заголовок** — самый тяжёлый элемент экрана: жирный вес, без ограничения ширины строки, максимальный размер.
- **CTA-кнопка** — второй по значимости после заголовка, визуально заметнее остального интерфейса (акцентный фон, при необходимости — мягкая пульсация в финальной сцене).
- **Подпись/поясняющий текст (`.lead`)** — приглушённый цвет, ограничен по ширине (~720px), сознательно легче заголовка и кнопки — не усиливать.
- **Второстепенные детали** (мета-подписи, даты, номера сцен) — самый лёгкий вес, мелкий размер.

## Тон текста

Дружелюбный, но сдержанный разговорный тон — без фамильярности и без агрессивных призывов. Простое, живое, уверенное действие без давления.

- Да: «Перейти в Telegram», «Что нового в HyperOS».
- Нет: «Подпишись прямо сейчас!», «Актуальная информация об обновлениях».

Короткие элементы (кнопки, бейджи, номера сцен) — по существу, без канцелярита и без восклицательных призывов.

## Цвета

- Фон: `#f7f5fb`
- Поверхность: `#ffffff`
- Текст: `#201a2b`
- Приглушённый текст: `#675f73`
- Акцент (кнопки, ссылки, бейджи, фокус): `#1753c5`
- Ошибка: `#a12b3b`

Акцент — единственный цвет для интерактивных элементов. Не смешивать с фирменным градиентом ниже.

## Фирменный градиент

Только фон вступительной и финальной сцены истории — не для текста, кнопок и других интерактивных элементов. Цвета сняты пипеткой с логотипа канала и осветлены смешиванием с белым (88%) — контраст текста поверх остаётся выше 14:1, что намного превышает порог читаемости:

- Фиолетовый: `#f1ecfa` (источник в логотипе — `#8863d4`)
- Синий: `#e4ebf9` (источник — `#1b55ca`)
- Оранжевый: `#feeae2` (источник — `#f74f0c`)

## Отступы

Используем шкалу `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`. Просторно, но не избыточно — плотнее, чем было изначально:

- Между сценами: `48–64px`.
- Внутри карточек: `20–24px`.
- Вступительная и финальная сцены истории: высота `70–75vh` (не `78vh`, как раньше).
- Одна главная мысль или одно действие на сцену — не перегружать экран, даже если место позволяет.

## Радиусы

- Поля и кнопки: `10–12px`
- Карточки: `16px`
- Крупные панели: `24px`
- Метки и бейджи (pill): `999px`

## Кнопки перехода в Telegram

- «Перейти в Telegram» — на всех промежуточных точках: карточки, пустые состояния, ошибка.
- «Подписаться» — только в финальной сцене истории, как единственный сильный призыв в конце.

## Типографика

- Основной текст: не меньше `16px`.
- Длинные абзацы: до `75` знаков в строке.
- Заголовки короткие.
- Длинный текст выравниваем по левому краю.

## Мобильная версия

- Колонки становятся одной колонкой.
- Главное действие остаётся рядом с контекстом.
- Интерактивные элементы удобно нажимать пальцем.
- Смысл не передаётся одним цветом.

## Анимация

- Элементы появляются при входе в область просмотра (reveal-on-scroll), а не сразу все — через `IntersectionObserver`, без новых библиотек.
- Несколько похожих блоков подряд (карточки, пункты списка) появляются по очереди, а не одновременно.
- Анимации используют принятый акцент; фирменный градиент — только фон вступительной/финальной сцены, новых цветов сверх акцента и градиента не вводим.
- При `prefers-reduced-motion: reduce` анимации отключаются — контент появляется сразу.
