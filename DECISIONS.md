# DECISIONS.md

## 2026-07-14 — Локальный режим по умолчанию

**Почему:** участник получает первый результат без базы, аккаунтов и ключей.

**Что меняет:** база подключается только после рабочего прототипа и проверки, что данные действительно нужны.

## 2026-07-14 — Архив вместо безвозвратного удаления

**Почему:** новичок может нажать не туда. Архив безопаснее.

## 2026-07-14 — Один акцентный цвет

**Почему:** так проще сохранить визуальную иерархию во время правок агентом.

## 2026-08-25 — Публичная лента статична, без CRUD

**Почему:** карточки со статусами «Черновик/Готовится/Опубликовано» и localStorage-хранилище остались от CRM-шаблона. У каждого посетителя было своё пустое хранилище в браузере, поэтому реальный человек с поиска видел пустую страницу вместо новостей.

**Что меняет:** лента новостей рендерится статически из `src/project.js` (поле `news`), публично показываются только записи со `status: "published"`. Экран `/workspace` с формой создания, сменой статуса и входом убран — контент правится прямо в файле, отдельный вход не нужен.
