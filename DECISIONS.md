# DECISIONS.md

## 2026-07-14 — Локальный режим по умолчанию

**Почему:** участник получает первый результат без базы, аккаунтов и ключей.

**Что меняет:** база подключается только после рабочего прототипа и проверки, что данные действительно нужны.

## 2026-07-14 — Архив вместо безвозвратного удаления

**Почему:** новичок может нажать не туда. Архив безопаснее.

## 2026-07-14 — Один акцентный цвет

**Почему:** так проще сохранить визуальную иерархию во время правок агентом.

## 2026-08-25 — Публичная лента статична, без CRUD

**Почему:** карточки со статусами «Черновик/Готовится/Опубликовано» и localStorage-хранилище остались от CRM-шаблона. У каждого посетителя было своё пустое хранилище в браузере, поэтому реальный человек с поиска видел пустую страницу вместо новостей.

**Что меняет:** лента новостей рендерится статически из `src/project.js` (поле `news`), публично показываются только записи со `status: "published"`. Экран `/workspace` с формой создания, сменой статуса и входом убран — контент правится прямо в файле, отдельный вход не нужен.

## 2026-09-01 — Сайт становится одной анимированной историей вместо ленты

**Почему:** решили не привязывать сайт к конкретной новости или к SEO-захвату по запросам — вместо ленты карточек нужна цельная скролл-история о канале с одной сценой на подписку в конце.

**Что меняет:** главный путь — не «поиск → карточка → клик», а линейная прокрутка через 6 сцен (см. `STORYBOARD.md`). Задача захвата по конкретным поисковым запросам снята сознательно — сайт работает как единая витрина канала, а не SEO-лендинг. Помеченная пригласительная ссылка на переход в Telegram остаётся — она теперь в финальной, 6-й сцене.

## 2026-09-03 — Фирменный градиент из логотипа как разрешённое исключение из «одного акцента»

**Почему:** правило «Один акцентный цвет» (2026-07-14) писалось для интерфейса без бренд-айдентики. Теперь есть логотип с фирменным градиентом (фиолетовый → синий → оранжевый), и владелец продукта явно попросил цвета сайта соответствовать айдентике логотипа.

**Что меняет:** `--accent` остаётся единственным цветом для интерактивных элементов (кнопки, ссылки, бейджи, фокус) — это не отменяется. Дополнительно разрешён фирменный градиент (сняты пипеткой с логотипа, осветлены до контраста текста >14:1) — но только как декоративный фон вступительной и финальной сцены истории, не для текста и не для интерактивных элементов. Правило и точные цвета — в DESIGN_SYSTEM.md.
