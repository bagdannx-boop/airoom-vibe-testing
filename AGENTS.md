# Правила работы AI-агента

— Перед изменениями прочитай `PRODUCT.md`, `FLOW.md`, `DESIGN_SYSTEM.md`, `DATA_MODEL.md`, `DECISIONS.md` и `TASKS.md`.
— Одна пользовательская задача за раз.
— Сначала покажи план и способ проверки, потом меняй только согласованный кусок.
— Не меняй архитектуру, модель данных и библиотеки без отдельного объяснения; лента новостей правится вручную в `src/project.js`, без CRUD и входа (см. DECISIONS.md, 2026-08-25).
— Не добавляй зависимости, если задача решается текущим стеком.
— После правок запусти `npm run check`.
— Покажи изменённые файлы, результат проверки и ручной чек-лист (включая телефон).
— Не помещай секреты и реальные персональные данные в код, логи, скриншоты и `runtime-config.js`.
— Если требования противоречат друг другу или файлам проекта — остановись и назови конфликт.
— После изменений обнови `PRODUCT.md`/`FLOW.md`/`DECISIONS.md` и этот файл там, где поменялось правило.
