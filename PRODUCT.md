# PRODUCT.md

## Для кого

Одна группа: люди, которые ищут именно новость, обновление или скрытую фичу, связанную с Xiaomi/Redmi/Poco/HyperOS — например «когда выйдет hyperos 4», «что нового в hyperos», «как включить [фичу] в hyperos».

Не целевые: те, кто ищет решение конкретной технической проблемы или ремонт устройства («Redmi не включается», «не заряжается») — они ищут ответ на свой вопрос, а не медиа, и не станут подписчиками.

Язык и регион не ограничивают аудиторию: не-русскоязычный посетитель с тем же намерением тоже целевой — контент канала на русском, но он сможет прочитать с переводчиком.

## Ситуация

Выходит обновление HyperOS (крупная версия) или появляется новость об Xiaomi/Redmi/Poco — утечка характеристик, цена, релиз устройства. Человек ищет это в поиске. Примеры запросов: «скачать обновление лаунчера на hyperos», «когда hyperos 4?».

## Текущий способ

Сейчас человек тратит время на сбор из нескольких источников: гуглит, читает разные Telegram-каналы, форум 4PDA, проверяет стандартную утилиту обновлений на устройстве. Продукт ориентируется на два конкурентных ориентира — чужие Telegram-каналы и официальный выпуск обновления Xiaomi по воздуху (OTA) — и должен быть не медленнее них.

## Полезный результат

Человек нажимает кнопку «Подписаться» и фактически подписывается на Telegram-канал «Xiaomi | HyperOS Updates», чтобы получать всё главное о Xiaomi, Redmi, Poco и HyperOS в одном месте, не собирая по разным источникам.

## Основной сценарий

1. Поиск — человек находит сайт по запросу в поисковике.
2. Интерес — видит ленту новостей. Если находит тему, которая зацепила, — читает её; если нет — сразу видит предложение подписаться, чтобы не пропустить следующую новость.
3. Полезная информация — если тема совпала, читает краткое содержание, достаточное, чтобы понять суть.
4. Переход в Telegram — нажимает кнопку «Перейти в Telegram»/«Подписаться»; кнопка показана всегда, независимо от того, совпала тема или нет.
5. Подписка — подписывается на канал ради полного материала и обновлений.

**Ограничение сценария:** лента из нескольких карточек не гарантирует совпадение с конкретным запросом человека — это ограничение V1. Страницы-под-новость из «Позже» — то, что реально обеспечивает совпадение с запросом.

## V1

- Лента новостей по Xiaomi, Redmi, Poco и HyperOS с кратким содержанием — реальный контент вместо демо-данных.
- Публично отображаются только новости со статусом «Опубликовано»; черновики и «Готовится» на сайт не попадают.
- Кнопка перехода в Telegram-канал на каждой карточке ленты (не только на главной), с помеченной пригласительной ссылкой — чтобы видеть в статистике канала переходы именно с сайта.
- Базовое SEO: title, meta description, H1/H2 с ключевыми словами (Xiaomi/Redmi/Poco/HyperOS), Lighthouse Performance ≥ 90 на мобильном и LCP < 2,5 с, мобильная вёрстка без горизонтального скролла. Без отдельных страниц под каждую новость — это минимальная находимость одной страницы.
- Свежесть ленты: показывать не больше 10–15 последних новостей, более старые скрывать из публичного вида — сайт с обещанием «актуальные новости» не должен выглядеть заброшенным в затишье между релизами.
- Название, заголовок и оформление сайта как источника новостей канала «Xiaomi | HyperOS Updates».

**Что проверяет V1:** механику воронки (лента → карточка → переход → подписка). Захват по конкретным поисковым запросам («скачать лаунчер на hyperos») V1 почти не проверяет — для этого нужны страницы-под-новость из «Позже». Решено осознанно: сначала механика, затем захват.

## Позже

- Отдельные SEO-страницы под каждую новость — следующий по важности шаг сразу после запуска, чтобы ловить конкретные запросы, а не только брендовые.
- Фильтры по устройствам — осмысленны примерно с 30+ новостей в ленте, когда её нельзя окинуть одним взглядом. Полнотекстовый поиск — с ~50+ карточек, или раньше, если уже есть страницы-под-новость (тогда есть по чему искать в архиве).
- Полноценная аналитика переходов (дашборд, воронка) поверх дешёвого замера через пригласительную ссылку.
- Sitemap и микроразметка — по мере роста числа страниц.

## Не делаем

- Регистрацию и личный кабинет.
- Публикацию полного текста новости на сайте — это единственный рычаг, оправдывающий переход в канал.
- Комментарии и реакции.
- Любую функцию, которая превращает сайт в самостоятельное медиа и удерживает читателя у себя — она работает против воронки.

## Ограничения

- Основной язык: русский.
- Основное устройство: телефон и ноутбук.
- Реальные персональные данные не используем до выбора подходящего хранилища.
- Секреты не попадают в браузер.
- Обновление ленты — событийное (триггер: крупный релиз HyperOS или заметная новость об Xiaomi/Redmi/Poco), не по расписанию; ведёт один человек — владелец канала.

## Критерии готовности

- Пользователь проходит главный путь без подсказки.
- Результат сохраняется или честно обозначен как локальный.
- На телефоне нет горизонтального скролла.
- Lighthouse Performance ≥ 90 на мобильном, LCP < 2,5 с.
- В течение 2–4 недель после запуска по помеченной пригласительной ссылке идут измеримые переходы (поток не ноль) — это подтверждает, что механика воронки работает. Ростовую цель по числу переходов в неделю ставим только после начала индексации, не в момент запуска.
- `npm run check` проходит.
